# TWA Food Showcase

Мини-витрина доставки еды для Telegram Web App: статическая страница на чистых HTML/CSS/JS, которая открывается внутри Telegram. Без сборщика, библиотек и backend. Сейчас это только каркас.

## Как открыть локально

```bash
npx serve .
```

Откройте адрес из вывода команды (обычно http://localhost:3000). В обычном браузере виден заголовок и пометка «Открыто в браузере».
